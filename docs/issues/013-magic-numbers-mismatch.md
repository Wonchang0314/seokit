# 매직 넘버 예외값 문서/config 불일치

## 문제

CODE_RULES.md §3.4.2:
> `0`, `1`, `-1` 같은 자명한 값은 예외

eslint.config.sample.mjs:
```js
ignore: [-1, 0, 1, 2, 100]
```

`2` 와 `100` 은 문서에 사유가 없고 자명하지 않다. `100` 은 도메인-특이값(퍼센트?)으로 보이는데, §3.4.2 의 정신("의미 있는 숫자는 상수로 추출") 과 충돌.

## 영향

문서와 실제 enforce 가 어긋남. 새 프로젝트로 복사하면 룰 의도가 흐려짐.

## 제안 해결

두 가지 중 택일:

- **(a)** 문서를 config 에 맞추고 `2`, `100` 의 사유를 본문에 명시.
  - `2`: 짝수/홀수 분기에서 흔하나 사실 `% 2 === 0` 등도 §3.4.2 의 정신상 상수화가 맞음
  - `100`: 백분율 계산. 명시적 상수(`PERCENT_MAX = 100`)로 빼는 게 더 맞음

- **(b)** config 를 문서에 맞춰 `[-1, 0, 1]` 만 남김 (권장)

권장: **(b)**. 도메인 값은 호출처에서 상수로 추출하는 게 §3.4.2 의 정신.

## 연결

[007](007-typescript-magic-numbers.md) 의 `@typescript-eslint/no-magic-numbers` 로 교체 작업과 동시 진행.
